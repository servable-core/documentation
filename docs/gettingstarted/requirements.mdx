# Requirements

### [Node JS](https://nodejs.org/en/download/)
Before you install Servable CLI, make sure Node.js is installed.

Recommended for current Servable engine stack: Node.js 22.x LTS or higher.

Minimum for CLI usage: Node.js 18.x or higher.

When installing Node.js, you are recommended to check all checkboxes related to dependencies.

### Docker (for local environment) 
- [Docker](https://docs.docker.com/get-docker)
👉 *Version 20.10.0 or above*
- Docker Compose
👉 *Version 2.20.0 or above*

The easiest and recommended way to get Docker Compose is to install Docker Desktop. Docker Desktop includes Docker Compose along with Docker Engine and Docker CLI which are Compose prerequisites.
[More](https://docs.docker.com/compose/install/)
