# Packages

## [Servable Server](https://github.com/servable-core/server)

`@servable/server` is the orchestrator: it computes the schema from every protocol applied to
your models, runs the docker-compose system launch, and wires each protocol's lifecycle (seed,
config, routes, jobs, triggers, services) on top of a framework engine.

<BashTabs npm={`npm install @servable/server`} />

## [Servable Tools](https://github.com/servable-core/tools) {#servable-tools}

`@servable/tools` is the schema/manifest engine used by both the server and the CLI: it builds and
validates the schema from a protocol graph, compiles and diffs the committed schema artifact
(`servable schema build`/`plan`/`apply`/`contract`), and extracts a protocol's manifest for
generated documentation. See [`@servable/tools` reference](./tools) for the full API.

<BashTabs npm={`npm install @servable/tools`} />

## [Servable Parse Server Engine](https://github.com/servable-core/parse-server-engine)

The currently only implemented engine: the adapter that lets Servable orchestrate protocols on
top of Parse Server, implementing Servable's engine API (Object, Query, Auth, Job, ...).
<BashTabs npm={`npm install @servable/parse-server-engine`} />

## [Servable CLI](https://github.com/servable-core/cli)

The Servable CLI scaffolds and manipulates Servable apps and protocols. See
[CLI command reference](./commands/install) for every command. It uses under the hood:
- `@servable/server`
- `@servable/tools`
- the Servable Protocols Registry API

<BashTabs npm={`npm install -g @servable/cli`} />


## [Servable Registry](https://servable.app)

The servable protocols registry is a centralized  protocols repository.

It is available at servable.app

It serves a public api at api.servable.app

## Servable Dashboard

The servable dashboard is a fork of the Parse Dashboard aimed at providing the best Servable experience.

It is available with the CLI when launching a full-fledged local app.

## [Servable VS Code Extension](https://github.com/servable-core/vscode)

An editor extension surfacing protocol resources, app structure, server status, and protocol
scaffolding directly in VS Code. Not yet published to the VS Code Marketplace. See
[VS Code Extension](./vscode-extension) for the full reference.
