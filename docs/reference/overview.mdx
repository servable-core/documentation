# Overview

Reference pages provide exact technical details: commands, options, and API-level behavior.

Use this section when you need precise syntax or implementation-level definitions.

:::info
Servable is still experimental and its API may change in the future.
:::

![logo](/img/icon.svg)

## In this section

- Commands: Servable CLI command syntax and flags.
- Lifecycle: startup and wiring order for runtime debugging.
- Model lifecycle: class registration and trigger execution behavior.
- Route and job contracts: runtime descriptor-level contract summary.
- Cloud function contracts: naming and registration rules.
- Trigger caveats: non-obvious runtime behavior and limits.
- Config adaptation: startup defaulting and engine configuration hooks.
- Engine: core runtime API domains such as object and query behavior.
- Protocol: protocol package layout and declaration reference.
- Packages: official package catalog and responsibilities.
- VS Code Extension: editor integration for protocols, app structure, status, and scaffolding.
