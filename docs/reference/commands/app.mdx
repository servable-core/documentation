# $ servable app

## Create a new app
Creates a new servable app and installs dependencies.
```bash
servable app new
```

### Options
```bash
  -n, --appName              App name                                                      [string] [default: "MyAppName"]
      --appDescription       App description                                             [string] [default: "A Servable app"]
      --engineId             Engine to use, e.g. @servable/parse-server-engine                                    [string]
  -i, --installDependencies  Install dependencies                                                [boolean] [default: true]
  -l, --license              License ("MIT", "Apache 2.0", ...)                                  [string] [default: "MIT"]
  -p, --packageManager       Package manager ('npm', 'yarn' or 'pnpm')                           [string] [default: "npm"]
  -g, --gitInit              Initialize a git repository                                         [boolean] [default: true]
  -d, --destination          Choose a destination                                                                 [string]
      --appPort              App port                                                             [number] [default: 1387]
```

`--engineId` picks which package's engine adapter the scaffolded app imports and installs. There is
currently one published engine, `@servable/parse-server-engine`, but the field is asked freely
(no hardcoded default) rather than fixed to it, since this is exactly the extension point a second
engine implementation would plug into.

### Example
```bash
servable app new --appName='MyApp' --engineId='@servable/parse-server-engine'
```

### Help
```bash
servable app -h
```
