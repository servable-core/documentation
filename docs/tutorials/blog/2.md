# 2. Add routes and background behavior

Now that your blog app boots with a `BlogPost` model, expose APIs and background processing.

## Add routes

Create route modules for read and write operations.

Suggested endpoints:

- `GET /blog/posts`
- `POST /blog/posts`

Use request/response schema contracts and keep handlers thin.

## Delegate logic to services

Move business logic (validation, transformations, side effects) to protocol services so it can be reused from jobs and triggers.

## Add background jobs

Use protocol jobs for non-blocking tasks, for example:

- Refreshing feed metadata.
- Sending notifications after publish.

## Validate locally

1. Restart the app.
2. Test route responses.
3. Confirm jobs are registered and executing.
4. Check health endpoint remains stable under load.
