# 1. Bootstrap the blog app

Create a new Servable app and start it locally.

```bash
servable app new --appName="MyBlog"
cd my-blog
yarn start
```

Then add a `BlogPost` model:

```bash
servable model add
```

Next, attach protocols to model declarations (for example `publishable`, `commentable`, and `taggable`) and restart the app.

Continue with route creation in [Guides: add route](../../guides/routes/add).
