# 1. Create a Parse-engine app

Servable can run on a Parse Server engine through the generated project defaults.

```bash
servable app new --appName="MyParseApp"
cd my-parse-app
yarn start
```

Validate runtime after startup:

1. Check `http://localhost:1387/servable`.
2. Check `http://localhost:1387/health-check`.
3. Open dashboard endpoints configured by your template.

If startup fails, use [Getting Started troubleshooting](../../gettingstarted/troubleshooting).
