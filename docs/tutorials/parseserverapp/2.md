# 2. Configure and verify runtime behavior

After bootstrapping your Parse-engine app, configure it for real environments.

## Configure environment values

Set environment variables for runtime-sensitive settings, including:

- App identity and port.
- Database and service connectivity.
- Protocol parameters used by routes/jobs.

## Verify startup lifecycle

On restart, check logs for:

1. Configuration resolution.
2. Schema validation, then the drift/compatibility-floor check, then an additive schema apply.
3. Route/job/service registration.
4. Health endpoint registration.

## Smoke test checklist

- `GET /health-check` returns success.
- Core app routes are reachable.
- Protocol-driven behavior appears as expected.

## Production readiness tips

1. Validate configuration in staging first.
2. Roll out schema-sensitive changes gradually.
3. Deprecate before removing (`schema.json`'s `deprecated: true`, then `servable schema contract` in a later release) so a rolling deploy never drops a field out from under an older pod.
